# Cozy Tent — web

Página del juego y política de privacidad, publicadas con GitHub Pages.

- `index.html`: portada, en español e inglés (el botón de arriba cambia el idioma).
- `privacidad.html`: política de privacidad, obligatoria para las tiendas.
- `img/`: icono y portada, sacados de los materiales de la ficha.

Para probarla en local: abrir `index.html` en el navegador.
